# IPL Analytics Dashboard 🏏

A modern and visually engaging IPL Analytics Dashboard built using HTML, CSS, JavaScript, and Chart.js.
This project presents key insights and statistics from IPL seasons (2007–2026) with an elegant dark-themed UI, animated cards, and interactive charts.

## Based on the uploaded file:

* 🚀 Features 

* 📊 Interactive Charts using Chart.js

* 🎨 Modern Dark UI Design

* ⚡ Smooth entrance animations

* 🏏 IPL statistics visualization

* 📈 Toss vs Match Outcome analysis

* 🔥 Phase-wise Run Rate comparison

* 🌟 Top Batters & Bowlers leaderboard

* 💡 Insight section highlighting key findings

* 📱 Fully responsive layout for mobile & desktop

## 📌 Dashboard Sections

### 🎲 Toss vs Match Outcome

Shows whether winning the toss affects match results.

## 📊 Phase-wise Run Rate

Compares average run rates of winners vs losers across:
* Powerplay Overs

* Middle Overs
  
* Death Overs
  
## 🌟 Hall of Stats

Includes:

* Top 5 Batters by Runs
  
* Top 5 Bowlers by Wickets
  
## 💡 Surprise Insight

Highlights the most impactful statistical finding from the dataset.
